# Extensions of distributional equivalence test-then-pool

Two follow-up studies of Yang, Liu & Evans (2026), *Data Fusion with Distributional Equivalence Test-then-pool* (arXiv:2603.11867):

- **Study A**: multiple historical control sources — risk-weighted borrowing, sourcewise equivalence fusion, selection-aware (full-reselection) permutation inference.
- **Study B**: shrinking equivalence radius / vanishing borrowing to remove the fixed-radius power blind spot (original Remark 3.19).

Progress log (GitHub Pages): https://yu-jusang.github.io/ttp-extensions/

Layout: `code/` simulation code, `results/` raw Monte Carlo output, `paper_A/`, `paper_B/` LaTeX sources and PDFs, `docs/` progress site.
Work in progress; see the log for status.
