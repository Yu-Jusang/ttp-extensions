01

개요

연구 A — 여러 historical source

여러 과거 대조군을 (i) 위험(risk) 기반 가중치로 결합하거나 (ii) source별 equivalence fusion 후 pooling. 같은 데이터에서 선택한 뒤 검정하는 문제를 permutation 재선택(full reselection)으로 다룸.

연구 B — shrinking radius / vanishing borrowing

원 논문 Remark 3.19의 검정력 사각지대를 반경 $\theta_n$ 또는 borrowing 비중 $b_n$을 사전에 정한 속도로 줄여 해결하는 방법과 그 대가(local power).

원칙

  • 최종 귀무가설은 항상 $H_0: Q_c = Q_t$.
  • $D$는 MMD(제곱 아님), 검정통계량은 $D^2$.
  • 모든 숫자는 실제 실행한 코드에서 나옴. 증명 못 한 것은 conjecture로 표시.
  • GPT 초안(2026-10-17)의 아이디어를 쓰는 부분은 출처를 밝힘.

계산 환경

로컬 PC

Windows 11, Intel CPU 16스레드 (worker 15개 병렬), Python 3.12.2, NumPy 2.5.4, SciPy 1.18.1, Matplotlib 3.11.2, TeX Live 2024.

공통 설정

RBF 커널 $k(x,y)=\exp\{-(x-y)^2/2\sigma^2\}$, $\sigma=1$ 고정(재현 실험만 median heuristic), $\alpha=0.05$, permutation $B=199$ ($L=200$), fusion bootstrap $B_f=199$.
